EngineX


Core Features

  • Forward Rasterizater Renderer:
    • Physically-based rendering BRDFs
    • Dynamic Multi-light with Shadow mapping
    • Percentage Closer Filtering shadows
    • Dynamic Texture Mip mapping
    • Stochastic Screen Space Reflections
    • Screen Space Ambient Occlusions
    • Screen Space Subsurface Scattering
    • Screen Space Refractions
    • Dynamic Multiple Sampling Anti Aliasing
    • Translucency rendering
  • Ray Tracing Renderer
    • Physically-based rendering (BRDFs, BTDF, BSSRDF)
    • Multi-light multiple importance sampling
    • Global illumination: path tracing & stochastic photon mapping for caustics (refractive & reflective)
    • True real-time volumetric random walk for participating media
    • Custom-built final image denoiser
    • Dynamic multi-sample control for each ray type and material
    • Individual Ray type recursion and number of samples control
  • Engine:
    • Multi-threaded multi-frame frame building/queueing
    • HDR pipeline with super sampling (SSAA) and super resolution (TAAU) support
    • Multi Scattering BRDFs and BTDF
    • Dynamic configurable render graph system
    • Parallax Occlusion mapping with multi level normal details mapping support
    • Dynamic adaptive bounding box generation
    • Geometries' mesh wireframe visualization
    • Physically based lens bloom effect
    • Multi-threaded Frustum culling
    • Dynamic objects' material modifcation and dynamic lights parameterization
    • Dynamic objects' transformations control
    • Full scene hierarchy support
  • Application/System:
    • Multi-threaded system work distribution
    • Real-time system analysis and monitor
    • Low latency raw hardware input read/process (mouse/keyboard)
    • Systen watch gaurd for launching multiple application instances
    • Vulkan backend support integration (ongoing)
  • Physics and Simulations:
    • Physically-based GPU-accelerated fluid simulation (Eulerian grid, ongoing)
